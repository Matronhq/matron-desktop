# Project origin

The Matron Desktop codebase began as a fork of Element Desktop. The current standalone repository keeps the copyright notices and licences required by the code that remains.

The Matrix-specific renderer bridge, event index, media authentication, native-module toolchain, SSO handling, and Element test fixtures have been removed. The remaining Electron packaging and operating-system integration includes code derived from Element Desktop; those files retain the original New Vector, Matrix.org Foundation, OpenMarket, and individual contributor notices alongside Matron's changes.

Element is a project of New Vector Ltd and contributors. Matrix is an open standard stewarded by The Matrix.org Foundation. Matron is not affiliated with or endorsed by either organisation.
